About

2人のプレイヤーが落ちてくるウイルスを砲台から出るアワで倒し、相手の陣地へ送る対戦シューティングです。 ウイルスが陣地下端に触れると、レベルに応じたダメージを受けます。

倒したウイルスは消えずに、1段階強くなって相手の陣地に送られます。 自分の陣地を守るために撃つほど相手への攻撃になり、相手が撃ち返せば、さらに強くなって戻ってきます。 連続で撃ち落とすとコンボが伸びて弾が3方向・5方向に広がり、 ボタンを長押しすると、ウイルスを貫通しながら大きくなるチャージショットを撃てます。

HPは顔のアイコンと連動していて、HP残量に応じて表情が変わります。 制限時間は3分で、決着がつかなければサドンデスに入り、両者のHPが1になります。

下の Events・Design・Code で紹介している仕組みとコードは、私が担当した部分です。主な担当は次のとおりです。

  • 試合中のイベント — 試合の停滞を検知して、ウイルスの加速などのイベントを起こす仕組み
  • プレイヤー操作 — 砲台の回転、ショットとチャージショットの入力、撃った後の反動
  • HPと被弾演出 — HPゲージと顔アイコンの切り替え、被弾時のゲージ点滅と陣地の揺れ
  • 決着からリザルトまで — KO演出、時間切れのサドンデス、ウイルスで画面を覆ってスコア画面へ切り替える遷移、スコア画面の演出
  • タイトル画面 — フェードイン、ロゴの揺れ、背景に降るウイルス

Events

試合が停滞したことを検知すると、盤面をかき乱すイベントを起こす仕組みを作りました。 イベントは10秒間続き、終わってから20秒間は次のイベントが起きません。

発生する条件

  • 開始から60秒たっても、両者のHPが50%を超えている
  • どちらかのHPが25%を切った（プレイヤーごとに1回ずつ。このときBGMも危険時の曲に切り替わる）
  • 20秒ごとの判定で、どちらかのHPの減りが5%未満だった（条件を満たさなかったときは、次の判定を10秒後に早める）

起きるイベント（4種類から抽選）

  • ウイルスがふえた！ — 0〜1秒おきに、両方の陣地へ3体ずつウイルスを追加する
  • ウイルスがつよくなった！ — 自然に出てくるウイルスが、最弱のLv1ではなく最強のLv5になる
  • ウイルスがはやくなった！ — すべてのウイルスの速度が2倍になる
  • ウイルスがぶんれつした！ — 撃ち落として相手に送るウイルスが、1体ではなく2体になる

Design

担当部分を作るにあたって工夫したことです。それぞれ、下の Code にあるファイルと対応しています。

押しっぱなしを「回数」ではなく「状態」で扱う

このゲームはショットにゲームパッドのほぼすべてのボタンを割り当てているため、 あるボタンを押したまま別のボタンを押し、先のボタンだけ離すと、チャージがリセットされてしまう問題が発生しました。 そこで入力を受け取る関数は「今押されているか」を記録するだけにし、 押した瞬間・離した瞬間は、毎フレームの状態の変化から求めるようにしました。 （PlayerManager.cs）

イベントの調整をインスペクターから容易にできるように。

イベントの種類・発生比率・イベントメッセージを構造体にまとめ、Inspector で編集できるようにしています。 比率を変えたり文言を直したりするときに、コードを触らずに済みます。 イベントの発生確率を%ではなく比で管理するとこで、インスペクターで値を変更しても矛盾が発生しないようにしました。 （EventManager.cs）

画面が隠れている間に、シーンを切り替える

リザルトからスコア画面へは、400体のウイルスが降り注いで画面を埋め、弾けて次の画面が現れる演出でつないでいます。 ウイルスが画面を覆い切った瞬間に裏でシーンを読み込み、スコア画面の準備も隠れているうちに済ませます。 落下先は格子状に配ってから少しずつずらし、隙間ができないようにしました。 落下は着地の瞬間に速度が0になるよう減速させています。 （VirusTransitionController.cs）

演出は止めずに、縮めてスキップする

ウイルスの遷移とスコア画面の登場演出は、ボタンを押すと短縮できます。 途中でコルーチンを強制停止すると、キャラやラベルが中途半端な位置に残るため、 スキップされたらフラグを立て、演出側が自分で最後の状態まで進めて終わるようにしました。 決着時は時間を止めているので、これらの演出は時間停止の影響を受けない経過時間で動かしています。 （ResultManager.cs / MainGameManager.cs）
