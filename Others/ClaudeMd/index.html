汎用CLAUDE.mdの作成と運用

プロジェクトごとに書き直さず、1つの土台をコピーして削って使う

About

私が Claude Code を使って開発を進める際に読ませるCLAUDE.mdの汎用版です。 新しいプロジェクトを始めるたびにこれをコピーし、そのプロジェクトに合わせて足したり削ったりして運用しています。

あわせて、Web 固有の規約をまとめた web-dev.md と、 プロジェクトで得た学びを蓄積する LESSONS.md を併用し、 セッションを跨いでも同じ失敗を繰り返さないようにしています。

最終更新：2026.9.23（Claude Opus 5.5 の登場に合わせて見直しを実施）

Files

役割ごとに3つのファイルに分けています。

CLAUDE.md

どのプロジェクトでも共通の土台。基本原則・作業の進め方・事前に許可を取る操作・報告の書き方に加え、 Unity / C++ / Python / SQL / Blender の言語・ツール別セクションを持ちます。

web-dev.md

HTML / CSS / JavaScript / PHP を扱うプロジェクトだけに置く追加規約。 セキュリティ・アクセシビリティ・命名は、こちらが CLAUDE.md より優先されます。

LESSONS.md

そのプロジェクト固有の「はまった問題・意外な挙動」を1件5行前後で蓄積するファイル。 Claude には作業前に読ませ、新しい学びが出たら追記させます。

How to Use

新しいプロジェクトを始めるときの手順です。

  1. コピーする — 汎用の CLAUDE.md をプロジェクトルートにコピーします。
  2. プロジェクト情報を埋める — 概要・技術スタック・ビルド / テスト / 実行コマンド・手を触れない場所を書きます。 分からない項目は空欄で残さず行ごと消します。空欄があると、Claude が推測で補ってしまうためです。
  3. 不要なセクションを削る — 「基本原則」〜「命名規則（共通）」と「Git」はそのまま残し、 言語・ツール別のセクションは使うものだけを残します。
  4. Web を扱うなら web-dev.md も置く — 扱わない場合は、CLAUDE.md 内の web-dev.md に触れている2行を消します。
  5. LESSONS.md を育てる — 原因調査に手間取った問題や、予想と違う挙動に出会ったら、 「症状・原因・解決・教訓」の形式で追記します。誤りと分かったエントリは消します。
